# SmartWaste – UI/UX Design

## Overview
This folder contains the AI-assisted UI/UX design for **SmartWaste**, a MERN-stack household scrap-selling and recycling platform.

The design follows the project's existing branding and green color theme.

## Design Features
- Consistent SmartWaste branding
- Green and white color palette
- Customer dashboard
- Scrap selling and pickup scheduling
- Pickup tracking
- Admin dashboard
- Responsive interface concepts

## Design Files
- `preview.html` – Browser-based design preview.
- `DESIGN-SYSTEM.md` – Colors, typography and design guidelines.

## Design Process
The initial UI/UX concepts were generated with AI assistance based on the existing SmartWaste project and its visual identity. The designs can be further customized and refined in Figma.

## Purpose
To maintain a consistent visual identity between the SmartWaste frontend implementation and its UI/UX design.
